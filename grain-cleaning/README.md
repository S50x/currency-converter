# لوحة مقارنة خطوط تنظيف نخالة القمح والشعير

صفحة ويب مستقلة (ملف واحد) لمقارنة موردي خطوط تنظيف وغربلة الحبوب من الشوائب، مع تكلفة الشحن والجمارك والضريبة حتى الوصول للسعودية.

## الرابط المباشر

بعد دمج هذا المجلد في فرع `main` تعمل الصفحة على:

https://s50x.github.io/currency-converter/grain-cleaning/

الرابط عام ويفتح عند أي شخص بدون تسجيل دخول.
